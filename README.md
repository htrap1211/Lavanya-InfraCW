# Lavanya Infrastructure Corporation Website

A modern, responsive website for Lavanya Infrastructure Corporation built with Vue 3, Vite, and SCSS.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

**Live Demo:** http://localhost:5173
